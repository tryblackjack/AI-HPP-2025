# AI-HPP Badge System

## Badge catalog
- **AI-HPP Verified**: bundle verification passed.
- **Reproducibility Certified**: independent rerun validated within tolerance.
- **Evidence Proven**: complete signed evidence package with integrity checks.

## Suggested criteria

### AI-HPP Verified
- Protocol version declared
- Schema/integrity/signature/timestamp checks passed

### Reproducibility Certified
- Third-party rerun report attached
- Environment snapshot complete

### Evidence Proven
- Mandatory artifact set complete
- Traceable lineage for data/model/code
