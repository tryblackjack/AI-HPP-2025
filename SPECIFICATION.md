# AI-HPP — Specification
Version: 4.1.1

## What is it
A simple standard that explains:
- how an AI system is structured
- what constraints it must adhere to
- what is needed for verification and audit

## Key Principles
1. **Transparency** — everything is recorded.
2. **Control** — the human is always in charge.
3. **Repeatability** — any result can be verified.
4. **Security** — harm is blocked in advance.

## Normative Parts (required)
- Architecture (AI_HPP_ARCHITECTURE_V4.md)
- Threat Model (THREAT_MODEL.md)
- Controls & Safeguards
- Evidence Recording
- Audit Rules

## Integration
For humans: this is a set of simple rules.
For engineers: documentation + diagrams.
For AI agents: formal rules for execution.
