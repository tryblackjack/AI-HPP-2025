# Conformance Levels
Version: 4.1.1

For a system to be considered AI-HPP compliant, it must pass one of the following levels:

## Level 0 — Minimum Security
- Human controller present

## Level 1 — Evidence Mode
- Everything is logged
- Every step can be explained

## Level 2 — Zero-Trust
- Actions are confirmed by a second agent

## Level 3 — Multi-Agent Safety
- Complex tasks are shared by multiple agents

## Level 4 — Cryptographic Verified
- Every operation is signed
- Changes cannot be tampered with

The level is chosen based on the task — a simple, clear gradient.
